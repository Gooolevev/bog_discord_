Асинхронный бот для Minecraft-сообщества на Python 3.11+ и discord.py 2.x:
slash-команды, интерактивные опросы, сбор команды, панель MC-сервера,
AI-помощник с юмором и построение Discord-сервера.

Начни с `/hello`: личное меню с разделами, кнопками и формами публикации.
Существующие команды сохранены; новые возможности работают без внешних API и новых зависимостей.

## Официальный сайт «Контур»

Сайт находится в `website/`: главная страница, светлая/тёмная тема, интерактивная
Discord-демонстрация, Spotify-проигрыватель и панель с Discord OAuth2.

```bash
cd website
npm ci
npm run dev
```

Адрес: **http://127.0.0.1:3000**. Для просмотра главной Discord-секреты не нужны.
Панель управляет мониторингом Minecraft, каналом уведомлений и стандартным временем опросов.
Настройки хранятся таблицей в существующей `data/community.sqlite3` и разделены по серверам.
Подключение OAuth2 и закрытого API описано в [инструкции сайта](website/README.md).
Без настройки `BOT_API_PORT` внутренний API выключен; `.env` автоматически не изменяется.

## Запуск

Установи зависимости из `requirements.txt` в виртуальное окружение.
Скопируй `.env.example` в `.env` и заполни `DISCORD_TOKEN`.

```bash
./venv/bin/python __main__.py
```

`python main.py` и `python .` запускают того же бота.
В Developer Portal включи **Message Content Intent** и **Server Members Intent**.
Для приглашения используй scopes `bot` и `applications.commands`.
Команды синхронизируются при подключении и вступлении на новый сервер.
Для обычной работы боту нужны просмотр канала, отправка сообщений и встраивание ссылок
(Embed Links); в ветках — отправка сообщений в ветках. Не выдавай Administrator ради опросов.
Привилегированные Intents нужны существующим функциям: упоминаниям AI, информации
об участниках и приветствиям при вступлении; опросы и сборы переписку не читают.

## Опросы, сбор команды и панель Minecraft

**Опросы.** `/poll вопрос:Что строим? варианты:Порт; Ферму; Вокзал минут:60`.
Без вариантов создаётся опрос «За / Против». Можно задать 2–6 разных ответов
до 80 символов каждый. «Голосовать» открывает личный Select Menu: один ответ
на участника, который можно изменить или снять. В карточке — доли голосов и шкалы.
Итоги фиксируются по таймеру или кнопкой автора/модератора; ничья отображается явно.
Имена голосующих публично не показываются, но ID и ответы хранятся в локальной SQLite:
это не криптографически анонимное голосование.

**Сбор команды.** `/сбор тема:Строим общую ферму мест:5 через:30`.
Организатор сразу занимает одно место. Кнопки «Я участвую» и «Выйти» поддерживают
актуальный состав; занять последнее место одновременно нескольким людям нельзя.
Время начала Discord показывает в локальном времени пользователя при наведении на дату.
С наступлением указанного времени запись закрывается; карточка сохраняет состав.
Это список записи, бот не создаёт голосовой канал и не отправляет личные напоминания.

Опросы и сборы можно создать формой через `/hello`. Перед отправкой форма явно
показывает, что карточка будет опубликована. Для публикации нужно право отправки
сообщений; для досрочного завершения — авторство или Manage Messages.
Публикации ограничены одной за 15 секунд на участника сервера, активных карточек
не более 20 на сервер. Между изменениями ответа — 2 секунды.
Таймер задаётся в минутах от 1 до 1440; размер команды — 2–50 человек.

**Minecraft.** `/server` публикует карточку с игроками, версией, откликом и адресом.
«Обновить статус» обновляет ту же карточку; «Как подключиться» даёт личную инструкцию.
Статус кэшируется на 20 секунд, параллельные запросы объединяются. Панель активна
5 минут, после чего кнопки отключаются; открыть новую можно через `/server`.
Список имён может быть неполным — это отдельно отмечено в карточке.

Карточки сообщества и ответы сохраняются в `data/community.sqlite3`, отдельно
для каждого Discord-сервера. Кнопки опросов и сборов работают после перезапуска.
Фоновая задача проверяет завершение каждые 30 секунд, в том числе после простоя бота;
после дедлайна новые ответы сразу отклоняются. При временной ошибке обновление
будет повторено. Удалённые сообщения не воссоздаются. Сохраняй весь каталог `data/`
при переносе хостинга. Личные меню и открытые формы после перезапуска нужно открыть заново.

## Настройки

| Переменная | Назначение |
|---|---|
| `DISCORD_TOKEN` | Токен Discord-бота, обязателен |
| `MC_SERVER` | Адрес Minecraft Java-сервера, по умолчанию `localhost:25565` |
| `MONITOR_CHANNEL` | ID текстового канала мониторинга; `0` или пусто — выключен |
| `POLLINATIONS_API_KEY` | Секретный ключ Pollinations для AI |
| `POLLINATIONS_MODEL` | Модель Pollinations, по умолчанию `openai` |
| `PORT` | Необязательный порт HTTP-проверки готовности: `/` возвращает 200 при готовности бота, иначе 503 |

Актуальный [API Pollinations](https://gen.pollinations.ai/docs) требует ключ из
[панели провайдера](https://enter.pollinations.ai). Запросы используют бюджет аккаунта.
Без ключа остальные команды работают, а AI сообщает об отсутствии настройки.
Одновременно выполняется один AI-запрос, затем действует пауза 45 секунд.

## Команды

- `/hello` — личная стартовая панель с меню и формами.
- `/ping`, `/roll`, `/coin`, `/choose`, `/random_user`, `/8ball`, `/rps`.
- `/avatar`, `/userinfo`, `/serverinfo`, `/poll` — информация и голосования.
- `/сбор` — команда с записью, лимитом мест и временем начала.
- `/server` — интерактивная панель Minecraft-сервера.
- `/ai` или прямое упоминание бота — вопрос нейронке. Сообщения других ботов игнорируются.
- `/построй` — роли, категории, каналы и форумы; только для администраторов.
- `/ресет` — предварительный просмотр удаления; для выполнения нужен параметр `подтвердить: True`.
- `/мониторинг` — диагностика мониторинга; только для администраторов.

Мониторинг проверяет сервер раз в минуту и сообщает о падении и восстановлении.
Входы и выходы игроков определяются только при получении полного списка имён от MC-сервера.

## Постройка и безопасный сброс

Для `/построй` боту нужны права администратора: шаблон включает административные роли
и настройку самого сервера. Для `/ресет` нужны права управления каналами и ролями.
Роль бота должна стоять выше управляемых ролей.
Без режима «Сообщество» форумы и трибуны заменяются текстовыми и голосовыми каналами.
Повторная постройка с тем же шрифтом использует существующие объекты.

ID созданных объектов записываются в `data/builder.sqlite3`. Сохраняй каталог `data/`
между перезапусками и при переносе хостинга. Он исключён из Git.
`/ресет` удаляет только учтённые объекты: текущий канал и его категория сохраняются,
категории с оставшимися каналами тоже. Ошибки удаления отражаются в отчёте.
Старые объекты, созданные до появления учёта, и объекты с совпадающими именами не удаляются.
Параметр `clean` у `/построй` также затрагивает только учтённые каналы бота.

## Разработка

Коги находятся в `bot/cogs/`, AI, хранилища и общий стиль интерфейса — в `bot/utils/`.
`community.py` содержит опросы, сбор команды и завершение карточек по таймеру;
`bot/utils/community.py` — транзакции SQLite, `bot/utils/ui.py` — карточки и обработку ошибок UI.
Новый ког зарегистрируй в `COGS` в `main.py`.

```bash
./venv/bin/ruff check .
./venv/bin/python -B -m unittest discover -s tests -v
```

Тесты работают без токена, подключения к Discord и внешних API; базы создаются
во временных каталогах. Проверяются гонки за места, изменение и снятие голосов,
права, таймеры, перезапуск, изоляция серверов, лимиты Embed, отказ Discord и кэш Minecraft.
