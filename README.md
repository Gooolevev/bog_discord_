# Discord Bot

Discord-бот на Python (`discord.py`), slash-команды, дерзкая нейронка, статус MC-сервера и автопостройка красивого сервера.

## Структура

```
bot_discord/
├── __main__.py          # точка входа: создание бота, загрузка когов, ретраи подключения
├── bot/
│   ├── cogs/            # модули с командами (коги)
│   │   ├── general.py   # /ping /hello /roll /coin /choose
│   │   ├── minecraft.py # /server — статус майнкрафт-сервера
│   │   ├── ai.py        # /ai + ответы на упоминания нейронкой
│   │   ├── builder.py   # /построй и /ресет — структура сервера
│   │   └── monitor.py   # автомониторинг MC-сервера (падение/подъём)
│   └── utils/
│       └── ai.py        # промпты, роасты, запросы к Pollinations
├── requirements.txt
├── .env                 # токены (в git не попадает)
└── AGENTS.md
```

## Запуск

```bash
source venv/bin/activate.fish   # fish; в bash: source venv/bin/activate
python __main__.py              # или: python -m __main__ / ./venv/bin/python .
```

Перед запуском: в `.env` задай `DISCORD_TOKEN` и (для /server) `MC_SERVER`.

## Команды (slash)

| Команда | Описание |
|---------|----------|
| `/ping` | задержка бота |
| `/hello` | приветствие |
| `/roll [грани]` | кубик, по умолчанию d6 |
| `/coin` | монетка |
| `/choose варианты` | случайный выбор (через запятую) |
| `/server` | статус майнкрафт-сервера |
| `/ai вопрос` | вопрос к нейронке (Pollinations, лимит 1 ответ/45с) |
| `/построй` | построить структуру сервера (только админы) |

Упомяни бота в сообщении — ответит нейронкой; пустой пинг — пошлёт.

## Автомониторинг сервера

Раз в минуту бот проверяет MC-сервер и пишет в канал при смене статуса:
🟢 «поднялся» (с онлайном, пингом и длительностью простоя) / 🔴 «упел».

Чтобы включить: в `.env` задай `MONITOR_CHANNEL` = ID канала
(ПКМ по каналу → «Копировать ID канала»; нужен включённый режим разработчика).
`0` или пусто — мониторинг молчит.

## Настройка в Discord Developer Portal

1. Приложение: https://discord.com/developers/applications
2. В разделе **Bot** включи **MESSAGE CONTENT INTENT**
3. Пригласи бота (URL Generator, scope `bot`)

## Как добавить новую команду

Создай ког в `bot/cogs/` (класс `commands.Cog` + `async def setup(bot)`),
команды — через `@app_commands.command(...)`, затем добавь модуль в список
`COGS` в `__main__.py`.
