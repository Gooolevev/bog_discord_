## 📌 Ключевые особенности

* 🗳️ **Интерактивные опросы и сборы:** Выбор вариантов через меню компонентов Discord, сохранение состояния в SQLite и таймеры закрытия.
* ⛏️ **Мониторинг Minecraft:** Карточка сервера с онлайном, пингом и инструкцией по подключению; фоновый трекинг статуса сети.
* 🤖 **AI-ассистент:** Умные ответы на базе Pollinations AI прямо в чате или по команде.
* 🏗️ **Конструктор сервера:** Автоматическое развёртывание структуры каналов, ролей и категорий в один клик.
* 🌐 **Веб-дашборд «Контур»:** Панель с поддержкой светлой/тёмной темы, авторизацией через Discord OAuth2 и встроенным плеером.

## 🚀 Быстрый старт

### 1. Подготовка окружения
Убедитесь, что у вас установлен **Python 3.11+**.

```bash
# Клонируйте репозиторий и создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните обязательный параметр `DISCORD_TOKEN` вашим токеном из [Discord Developer Portal](https://discord.com/developers/applications).

> ⚠️ **Важно:** В Developer Portal во вкладке **Bot** обязательно включите **Message Content Intent** и **Server Members Intent**. Для приглашения используйте scopes: `bot`, `applications.commands`.

### 3. Запуск бота
```bash
python __main__.py
```

## 🌐 Веб-панель «Контур»

Интерфейс панели управления расположен в каталоге `website/`. Позволяет настраивать таймеры опросов, каналы логов и мониторинг Minecraft-сервера индивидуально для каждой гильдии.

```bash
cd website
npm ci
npm run dev
```

Локальный адрес: **http://127.0.0.1:3000**  
*Для простого запуска главной страницы секреты Discord не требуются. Подробнее о подключении OAuth2 читайте в [инструкции сайта](website/README.md).*

## 💡 Основной функционал

### 🗳️ Интерактивные опросы
* **Команда:** `/poll вопрос:Что строим? варианты:Порт; Ферму; Вокзал минут:60`
* Поддержка от 2 до 6 вариантов ответов (до 80 символов). Без указания вариантов создаётся быстрый опрос «За / Против».
* Голосование происходит через **Select Menu**: каждый участник может в любой момент изменить или снять голос.
* Результаты и шкалы обновляются в реальном времени; ничьи определяются автоматически.

### 👥 Сбор команды
* **Команда:** `/сбор тема:Строим общую ферму мест:5 через:30`
* Организатор автоматически занимает первый слот.
* Участники записываются и выходят через интерактивные кнопки. Discord отображает время начала в локальном часовом поясе каждого пользователя.
* Защита от состояния гонки (Race Condition) на последнее свободное место.

> 💡 **Совет:** Опросы и сборы также можно удобно создавать через единое всплывающее окно команды `/hello`.

### ⛏️ Интеграция с Minecraft
* **Команда:** `/server` публикует статусную карточку: текущие игроки, версия, пинг и адрес подключения.
* Кнопка **«Обновить статус»** актуализирует информацию без спама новыми сообщениями (кэш 20 секунд).
* Фоновый мониторинг проверяет доступность сервера каждую минуту и отправляет оповещения о падении или восстановлении в `MONITOR_CHANNEL`.

## 📜 Список команд

| Команда | Описание | Доступ |
|---|---|---|
| `/hello` | Личная стартовая панель: быстрое меню, справка и формы | Всем |
| `/server` | Статус Minecraft-сервера и инструкция по входу | Всем |
| `/poll` | Создание опроса с таймером и кнопками | Всем |
| `/сбор` | Запись участников на ивент/рейд с ограничением мест | Всем |
| `/ai` *(или @упоминание)* | Задать вопрос встроенному AI-ассистенту | Всем |
| `/avatar`, `/userinfo`, `/serverinfo` | Карточки с подробной информацией | Всем |
| `/ping`, `/roll`, `/coin`, `/choose`, `/8ball`, `/rps` | Набор мини-игр и рандомайзеров | Всем |
| `/построй` | Авторазвертывание структуры каналов и ролей | Администраторы |
| `/мониторинг` | Диагностика системы проверки Minecraft-сервера | Администраторы |
| `/ресет` | Безопасная очистка созданных ботом каналов | Администраторы |

<details>
<summary><b>🛠️ Подробнее о командах развертывания (/построй и /ресет)</b></summary>

* Для выполнения `/построй` боту требуются права Администратора, а его роль должна находиться выше создаваемых ролей.
* Все созданные ID сохраняются в `data/builder.sqlite3`.
* Команда `/ресет` удаляет **только** те сущности, которые бот создал сам, защищая ваши старые каналы и категории от случайного удаления. Для запуска требуется флаг `подтвердить: True`.
</details>

## ⚙️ Конфигурация

Все параметры передаются через переменные окружения в файле `.env`:

| Переменная | По умолчанию | Описание |
|---|:---:|---|
| `DISCORD_TOKEN` | *обязательно* | Токен авторизации Discord бота |
| `MC_SERVER` | `localhost:25565` | Адрес Minecraft Java-сервера |
| `MONITOR_CHANNEL` | `0` (выкл) | ID канала для уведомлений о статусе сервера |
| `POLLINATIONS_API_KEY` | — | Секретный ключ [Pollinations](https://enter.pollinations.ai) для работы AI |
| `POLLINATIONS_MODEL` | `openai` | Используемая языковая модель |
| `PORT` | — | Порт для HTTP Healthcheck (возвращает `200` при готовности бота) |

## 💻 Разработка и тестирование

Проект спроектирован по модульной структуре Cogs:
* `bot/cogs/` — логика команд, разбитая по модулям.
* `bot/utils/` — работа с транзакциями SQLite (`community.py`), отрисовка Embed-компонентов и обработка ошибок (`ui.py`).
* `data/` — локальные базы данных SQLite (исключены из Git, обязательно сохраняйте при переносе на другой сервер).

```bash
# Проверка качества кода линтером
./venv/bin/ruff check .

# Запуск модульных тестов (без необходимости Discord-подключения)
./venv/bin/python -B -m unittest discover -s tests -v
```
